# Manufacturing

| Stage | Process |
|---|---|
| Fabrication | PCBs to IPC-6012 |
| Assembly | Contract manufacturer, IPC-A-610 Class 2 and J-STD-001 |
| Test | Automated functional test: supply, sequencing, UART link to the modem, IMEI read |
| Serialization | Serial number, lot and date code linked to IMEI and test record |
| Labeling | Part number, serial, revision, IMEI, scannable code |
| Packaging | ESD protective |

Quality targets are in [09 Compliance and quality](../../docs/09_Compliance_and_Quality.md). Test fixture design, data format, limits and retention period **[Pending decision]** will be defined before PVT.
